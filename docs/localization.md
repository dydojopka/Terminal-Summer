# Английская локализация

Переключение: кнопка **RU / EN** в верхнем правом углу главного меню или
**Настройки → Язык → English**. `Русский`
включает исходный текст. Сценарии `TS/text/*.txt` и формат сохранений не
меняются. Сохранённый кадр диалога может остаться на исходном языке; следующая
реплика использует язык из настроек.

Сценарный английский, имена персонажей и подписи карты взяты из Steam-версии
Everlasting Summer. Каталог `TS/text/en/<глава>.json` хранит хеш русского
сценария, готовые позиции и ID блоков Ren'Py (или исходную подпись меню).
При несовпадении хеша игра показывает русский, а не перевод другой реплики.
`TS/text/en/import-report.json` перечисляет строки, которые импортёр не смог
сопоставить. Отдельные экраны и тексты вне TXT (например, карточный стенд)
этим импортом не переводятся.

Полные английские объявления главного меню записаны в `TS/text/en/main-menu.json`.
В оригинале они нарисованы на фоне `images/gui/title_menu/mainmenu_en_ground.jpg`
из `game/archive.rpa`; для терминала убраны только переносы слов с картинки.

Настройки, список концовок, экран завершения и титры терминальной адаптации
используют `settings-menu.json` и `endings-menu.json`. Названия всех 13 маршрутов
взяты из английского словаря Steam-версии, названия достижений — с английских
изображений `images/misc/ach/` в `game/archive.rpa`, выбранных по `ach_table`
из `game/script.rpyc`.

Подписи галереи и музыкальной комнаты вынесены в `gallery-menu.json`, а подсказки
клавиш игровой нижней панели — в `footer.json`. Названия треков и сами
горячие клавиши не зависят от выбранного языка.

Меню загрузки и сохранения, включая предупреждение об устаревшем файле,
использует `save-menu.json`. Превью показывает снимок реплики из файла сохранения.
Подписи карточного турнира, паузы, подготовки сцен и предупреждений терминала
содержатся в `runtime-ui.json`. Отдельный отладочный карточный стенд из `scripts/`
и надписи внутри исходных изображений не входят в эту локализацию.

После изменения сценариев пересоберите каталог из установленной новеллы:

```sh
python scripts/import_english.py --steam-game "/путь/к/Everlasting Summer"
```

Добавьте `--check`, чтобы сверить файлы с оригиналом без перезаписи. В сборке
`python scripts/import_english.py --check` проверяет хеши и покрытие без Steam.
Менять сгенерированные английские реплики вручную не нужно: спорные пары
проверяются по русскому сценарию и ID исходного блока. Условия публикации — в
[`LICENSING.md`](../LICENSING.md).
